# 🎓 LEARNO — Learning Discovery Platform

### Discover. Learn. Practice. Grow.

LEARNO is a learning-focused discovery platform that helps students, developers, and anyone interested in technology find useful learning resources in one place.

Instead of searching multiple websites separately, LEARNO provides a simple learning search experience for discovering courses, tutorials, roadmaps, documentation, practice platforms, videos, and other educational resources.
